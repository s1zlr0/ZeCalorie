# ZeCalorie

Простое настольное приложение для учёта питания: добавление приёмов пищи, расчёт КБЖУ, дневная норма калорий и история по дням.

## Возможности

- Добавление приёма пищи (категория, название, калории, белки/жиры/углеводы)
- Удаление записей за текущий день
- Установка дневной нормы калорий вручную
- Расчёт нормы по формуле Миффлина-Сан Жеора (пол, вес, рост, возраст)
- Просмотр итогов за сегодня (съедено / осталось до нормы)
- История приёмов пищи по датам
- Хранение данных локально в файлах `meals.json` и `settings.json`

## Запуск из исходников

Требуется Python 3.9+ (используется только стандартная библиотека `tkinter`).

```bash
python zecalorie.py
```

## Сборка в exe (Windows)

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name ZeCalorie --icon=assets/app_icon.ico --add-data "assets;assets" zecalorie.py
```

Готовый файл появится в папке `dist/ZeCalorie.exe` — уже со своей иконкой.

> Флаг `--icon` задаёт иконку самого exe-файла, а `--add-data` копирует папку `assets` внутрь сборки, чтобы иконка отображалась и в заголовке окна при запуске. На macOS/Linux вместо `;` в `--add-data` нужно использовать `:` (например `"assets:assets"`).

## Структура данных

`meals.json` — список приёмов пищи:

```json
{
  "date": "2026-09-14",
  "category": "Завтрак",
  "name": "Овсянка",
  "calories": 320,
  "protein": 10,
  "fat": 6,
  "carbs": 55
}
```

`settings.json` — настройки пользователя (дневная норма калорий).
